OPTIONAL / PUBLIC PROFILE

Keep a longer-running profile with tokenmaxxing.

tokenmaxxing can accumulate daily aggregates each time you sync. It cannot recover local logs that were already deleted, but it can retain data you have already synced.

This uploads data publicly. It sends daily dates, model names, source names, token counts, and API-equivalent estimates. Prompts and session text are not uploaded.

Read tokenmaxxing privacy and setup ↗

macOS / Linux

if command -v bun >/dev/null 2>&1; then bun install -g @851-labs/tokenmaxxing@latest; else npm install -g @851-labs/tokenmaxxing@latest; fi && tokenmaxxing bootstrap

Windows PowerShell

if (Get-Command bun -ErrorAction SilentlyContinue) { bun install -g @851-labs/tokenmaxxing@latest } else { npm install -g @851-labs/tokenmaxxing@latest }; if ($?) { tokenmaxxing bootstrap }

The local report keeps usage on this computer. It downloads public pricing and Go plan metadata, then opens a local file. Tokenmaxxing is a separate, opt-in command that publishes daily aggregates to a public profile.
